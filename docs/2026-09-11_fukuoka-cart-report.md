# カート試作の実装・検証

## 実装
- 商品カードの数量選択とカート追加。複数施設をまたいで選択可能。
- 明細ごとの数量変更・削除、別の受取分を1点追加。
- 商品カテゴリに応じた受取場所・日時の選択。同カテゴリへの一括適用には画面内の確認を表示。
- 一般／会員区分をカート全体に適用。商品・施設・受取条件は元のマスタを分離して継承。
- 配達料は配達対象の申込施設数×1,000円。施設内の複数明細で重複しない。正式な複数施設注文の料金運用は別途確認が必要。
- 固定カートバーに点数・合計を表示。文字サイズボタンと重ならない配置。
- お客様情報の入力は一度。確認画面を申込施設別に集約。
- ブラウザのsessionStorageにカートと価格区分を保存。個人情報の保存は行わない。
- テスト画面のため注文・メールの送信処理なし。既存の本番フォーム・Workerは変更なし。

## 検証
- No.7、8、9、5を各1点：一般85,000円／会員82,000円。
- No.9を別明細で1点追加、No.7とNo.9の2施設で配達：商品110,000円＋配達2,000円＝112,000円。No.9が2明細でも同施設の配達料は1,000円。
- No.5を別受取で1点追加：6点117,000円。12/24アヴィオと12/25ロイヤルの別条件が確認明細に表示。
- 施設別合計：ガーデン67,000円／ロイヤル29,000円／アヴィオ21,000円。合計117,000円。
- 同カテゴリへの受取条件コピー：確認ダイアログ→適用後に別明細へ場所・日時が反映。
- 再読み込みでカートを復元。数量変更51,000円→80,000円、全削除で0点0円。
- 必須情報不足エラー、送信なしの最終明細を確認。
- スマートフォン390px設定で横はみ出しなし。カート・受取選択・固定バーを目視確認。
- JavaScript構文チェック、ブラウザJSエラーなし。本番ディレクトリの差分なし。
