## 実施内容
- 新規フォルダ `public/bridal-ring/` を作成（既存ファイルの変更なし）
  - index.html（v0001）／worker.js（v0001）／wrangler.toml／.htaccess／README.md
- 構成は既存おせちフォームと同じ標準：Cloud Run ＋ Cloudflare Worker ＋ Brevo
- 参加希望日時：チェックボックス（複数選択可）を採用。第1希望だけだと日程が合わない時に再調整の手間が増えるため。日付ごとに時間枠カード表示、満席指定・過去日自動非表示に対応
- 結婚予定：今月〜24か月先＋「◯年◯月以降」＋「未定」を自動生成（毎月の更新作業不要）
- 連絡先：電話・メールとも必須（メールは自動返信に使用）
- 郵便番号→住所自動入力（zipcloud JSONP）
- GTM-KG9CZ8Q4 設置、送信成功時に `bridal_ring_submit` を dataLayer へ送信
