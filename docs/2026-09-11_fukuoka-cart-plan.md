# カート形式のテスト改修

- 対象：fukuoka-2026-testのみ。復旧地点043e8cb。既存本番・Worker・API・DBは変更なし。
- 複数施設の商品をカートに追加。数量変更・削除・別受取分の追加、明細ごとの場所／日時選択。顧客情報は一回。
- 価格・施設・受取選択肢は既存マスタを継承。会員区分は全明細に適用。
- 配達料は従来の施設別申込を踏襲し、配達商品がある申込施設ごとに1,000円。同施設のおせち複数明細には重複加算しない。複数施設分の合算ルールは正式受付前の確認事項。
- セッション内に商品・数量・受取条件・価格区分のみ保存。名前・住所・メールは保存しない。
- メール送信は実装しない。確認画面は施設別にまとめ、個人情報を外部送信しない。
- 確認：複数施設、異なる日時／場所、同一商品別受取、価格変更、削除・空カート、配達料重複防止、入力エラー、スマートフォン、公開URL。
- テストURL公開まで許可済み。変更コミットのrevertで復旧。
