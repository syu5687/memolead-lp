# 福岡おせち2026 商品紹介テストページ

## 掲載方針
商品分類（おせち5・クリスマス6・鍋2）を入口にし、写真 → 人数・品目数 → 商品名 → 一般／会員価格 → 申込施設 → 注文欄へのボタン、の順で統一した。初期表示はおせち、全商品表示も可能。詳しい献立は開閉式。

商品選択ボタンは対応施設を選んで数量欄へ移動する。数量は自動加算しない。別施設への切替時に数量が入っている場合は、消える内容を確認してから切り替える。

申込施設と受取場所が異なること、施設ごとの申込みが必要なことを注文前に説明。低画質PDFの細かな文字を画像として掲載せず、価格・条件はHTMLで記載。
